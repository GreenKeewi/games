# Games

A responsive, keyboard-accessible HTML/CSS hub for GreenKeewi's browser games. Serve this directory with any static server; no build step, account, analytics or backend is required.

All five previews are actual gameplay captures. Source commits, capture methods, runtime hashes, tested behavior and exact Pages deployment jobs are recorded in [verification](verification/README.md). Local browser evidence is distinguished from direct public-origin verification, which is currently blocked by this cloud's proxy. Earlier release evidence is retained as historical material.

Game links open in the same tab. The original 2D Taxi remains separately linked and preserved. Skybreak strike completion and the native menu/link keyboard paths in both 3D taxi copies have dedicated regressions in their source repositories.
