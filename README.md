# Games

A small, responsive HTML/CSS hub for GreenKeewi’s browser games.

Open `index.html`, or serve this directory with any static server. No build step, framework, accounts, analytics, or backend.

Game links become active only after their individual published builds have been verified. Preview images are labeled as artwork or gameplay accurately.

The existing taxi games are linked without modifying their repositories. All links open in the same tab, so browser Back returns to the hub.
